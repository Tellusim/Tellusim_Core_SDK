The Intel oneAPI Base Toolkit is required

https://www.intel.com/content/www/us/en/developer/tools/oneapi/base-toolkit-download.html

D:\Intel\oneAPI\compiler\2025.3\bin must be added to your PATH environment variable.

The following environment variables must also be set:

* ONEROOT to the oneAPI installation directory (D:\Intel\oneAPI)

* LEVEL_ZERO_V1_SDK_PATH to the LevelZeroSDK directory (set automatically by the Intel GPU driver)
